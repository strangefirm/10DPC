This repository contains a collection of solutions to the "10 Days Python Challenge," 
aimed at enhancing Python programming skills through a series of daily assignments. 
Each day presents a unique problem or concept that encourages users to deepen their understanding of Python and its applications.

Repository Structure

The repository is organized into individual folders or files for each day's challenge,
making it easy to navigate through different topics.
Below is a brief outline of the structure:

Day 1: Example for Arithmetic operations and Operations with String
Day 2: Example using all Datatypes.
Day 3: Example of IF,NESTED IF and Ternary IF
Day 4: For Loop using list and dictionary
Day 5: Operations using List
Day 6: Operations using Dictionary
Day 7: Operations using Set and Frozen Set
Day 8: Building a calculator Using Functions
Day 9: Installing 10 modules and importing them in the program
Day 10:Building a snake game with UI
